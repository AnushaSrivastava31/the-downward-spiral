# **The Downward Spiral**🌀
A quirky corner of the internet for the endlessly curious

Live website: [https://the-downward-spiral.onrender.com]

## About:

This is a personal website for making fun facts, random challenges, and rabbit holes exciting. Designed with a plum and cream aesthetic, it turns everyday curiosity into a little adventure.

## Features:

**The Randomiser** — Discover unexpected facts.

**The Rabbit Hole** — Follow your curiosity into unusual topics.

**Tiny Challenge** — Take a break with small challenges and puzzles.

**Why Does This Exist?** — Explore strange historical curiosities.

**Saved Archive** — Bookmark interesting discoveries to revisit later.
